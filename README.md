# Linas recept

Linas kokbok som interaktiv webbsida: 89 recept i fyra flikar. Varje tallrik ritas i webbläsaren, ur receptets egna ingredienslista.

- Matlagningsläge med steg och timers
- "Vad har du hemma?" – hitta recept utifrån det du har
- Snurra fatet – slumpa fram middag
- Visningsläge – bildspel genom hela boken

Allt ligger i en enda fil: `index.html`.
